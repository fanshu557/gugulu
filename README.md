# 咕噜咕噜 (GuluGulu)

可爱心情日记与解压App

## 功能介绍
- 🫧 魔法工坊 - 用情绪因子熬制心情泡泡
- 🎮 解压小游戏 - 捏泡泡纸、揉揉团子、撕纸片、听雨声
- 🏝️ 心情岛屿 - 你的情绪可视化地图
- 🧸 小咕噜 - 情绪小精灵陪伴成长
- 🏆 成就系统 - 记录每一个小进步
